Where it goes:
  1. Open prime-wear-collections-254.html in any text editor (Notes app, Notepad, or GitHub's web editor).
  2. Find the block that starts with const PRODUCTS = [.
  3. Paste the copied line in anywhere inside that list — just make sure it sits between two existing { ... }, lines, or right before the closing ];.
  4. Save the file. If a new category was used, also add it to the filter list — find const CATS = [ just below PRODUCTS and add a line like {id:'yourcategoryid', label:'Your Category Name'}, so it shows up as a filter button.
